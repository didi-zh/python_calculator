# 🧮 Calculator with Prioritisation

---

A desktop calculator application built in **Python** using a Graphical User Interface (GUI). This project focuses on implementing custom logic to handle **operator prioritisation** (the correct order of operations, such as evaluating multiplication and division before addition and subtraction).

---

## 🌟 Key Features

---

* **Smart Prioritisation Logic:** Respects strict mathematical rules instead of calculating inputs blindly from left to right.
* **Graphical User Interface (GUI):** Designed with Python's built-in `tkinter` library for a clean, responsive desktop application experience.
* **Error Handling:** Safely manages edge cases such as division by zero, syntax errors, and invalid inputs without crashing.
* **Interactive Buttons:** Seamlessly Connects screen buttons to the calculation logic.

---

## 🛠️ Tech Stack

* **Language:** Python 3
* **Library:** `tkinter` (GUI)
